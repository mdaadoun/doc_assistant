## 1. Executive Summary & Pedagogical Context

A enterprise entity, **Helvetia Consulting**, maintains an internal documentation repository containing approximately **5,000 pages** (HR policies, standard legal contracts, technical specifications, and meeting minutes) formatted across PDF, DOCX, and Markdown files. Knowledge workers currently waste significant billable hours manually retrieving specific clauses, error codes, and operational procedures from this unindexed dataset.

The objective of Project 5 is to deliver a **production-grade Retrieval-Augmented Generation (RAG) platform** capable of executing natural language queries against this large-scale corpus with deterministic precision. The system must adhere to two non-negotiable architectural constraints:

1. **Precision Over Scale**: Retrieval accuracy and context relevance must remain stable across a 5,000-page dataset (~2.5 million tokens). Pure vector lookups without lexical hybridization or cross-encoder re-ranking are strictly forbidden.
2. **Mandatory Source Attribution**: Every factual assertion generated by the system must contain an explicit, traceable citation pointing to the exact document name and page number. Unverified or uncited answers are classified as critical system failures regardless of their surface plausibility.

Evaluation for this project focuses primarily on **system reliability, retrieval recall, and anti-hallucination guardrails**, rather than visual interface polish.

## 2. Functional Scope

### 2.1 Mandatory Requirements (Must-Have)

| Requirement ID | Module | Technical Description |
| --- | --- | --- |
| **FR-01** | Corpus Ingestion | Consume PDF, DOCX, and Markdown files via the Project 4 pipeline using recursive structural chunking (512 tokens max, 10% overlap) with differential update handling. |
| **FR-02** | Hybrid Indexing | Persist dual representations for every chunk: dense vector embeddings (via Qdrant or `pgvector`) and sparse lexical indices (via BM25). |
| **FR-03** | Hybrid Retrieval & Fusion | Execute parallel dense and sparse searches, merging the top 50 candidates from each path using Reciprocal Rank Fusion (RRF, $k=60$). |
| **FR-04** | Cross-Encoder Re-Ranking | Route the top 30 fused candidates through a cross-encoder model (Cohere Rerank API or local FlashRank ONNX) to select the top 5 chunks for context injection. |
| **FR-05** | Grounded Generation | Pass the top 5 context chunks to the LLM alongside a strict isolation prompt that restricts answers to the provided context. |
| **FR-06** | Mandatory Citation Engine | Format every factual claim with an inline reference matching the source metadata: `[Doc: <file_name> |
| **FR-07** | Confidence & Honesty Filter | Intercept retrieved candidates prior to LLM generation. If the top re-ranking score falls below a calibrated confidence cutoff ($S_{\text{min}} < 0.35$), bypass generation and return a standard refusal response: *"I cannot answer this question based on the available documentation."* |
| **FR-08** | Interactive Client Interface | Provide a React + Vite interface supporting query input, streaming answers, and clickable citation drawers that display the original context excerpt. |
| **FR-09** | Retrieval Observability | Expose a `/api/v1/debug/retrieval` endpoint providing full inspection of raw dense scores, BM25 scores, fused RRF ranks, and re-ranker weights for any query. |

## 6. System Implementation

### 6.1 Core Retrieval Engine (`src/retrieval/engine.py`)

```python
import uuid
from typing import Any, Dict, List
from flashrank import Ranker, RerankRequest
from qdrant_client import QdrantClient
from qdrant_client.models import Distance, PointStruct, VectorParams
from rank_bm25 import BM25Okapi


class ProductionHybridEngine:
    def __init__(
        self,
        qdrant_host: str = "localhost",
        qdrant_port: int = 6333,
        confidence_threshold: float = 0.35,
    ) -> None:
        self.qdrant = QdrantClient(host=qdrant_host, port=qdrant_port)
        self.collection_name = "helvetia_docs"
        self.confidence_threshold = confidence_threshold
        self.bm25_corpus: List[Dict[str, Any]] = []
        self.bm25_model: BM25Okapi | None = None
        self.reranker = Ranker(model_name="ms-marco-MiniLM-L-6-v2")

        if not self.qdrant.collection_exists(self.collection_name):
            self.qdrant.create_collection(
                collection_name=self.collection_name,
                vectors_config=VectorParams(size=1536, distance=Distance.COSINE),
            )

    def index_corpus(
        self, chunks: List[Dict[str, Any]], embeddings: List[List[float]]
    ) -> None:
        points: List[PointStruct] = []
        tokenized_corpus: List[List[str]] = []

        for chunk, vector in zip(chunks, embeddings, strict=True):
            point_id = str(uuid.uuid4())
            chunk["chunk_id"] = point_id

            points.append(
                PointStruct(id=point_id, vector=vector, payload=chunk)
            )
            self.bm25_corpus.append(chunk)
            tokenized_corpus.append(chunk["text"].lower().split())

        self.qdrant.upsert(collection_name=self.collection_name, points=points)
        self.bm25_model = BM25Okapi(tokenized_corpus)

    def _reciprocal_rank_fusion(
        self,
        dense_hits: List[Dict[str, Any]],
        sparse_hits: List[Dict[str, Any]],
        k: int = 60,
    ) -> List[Dict[str, Any]]:
        rrf_scores: Dict[str, float] = {}
        doc_map: Dict[str, Dict[str, Any]] = {}

        for rank, item in enumerate(dense_hits):
            doc_id = str(item["chunk_id"])
            doc_map[doc_id] = item
            rrf_scores[doc_id] = rrf_scores.get(doc_id, 0.0) + (1.0 / (k + rank + 1))

        for rank, item in enumerate(sparse_hits):
            doc_id = str(item["chunk_id"])
            doc_map[doc_id] = item
            rrf_scores[doc_id] = rrf_scores.get(doc_id, 0.0) + (1.0 / (k + rank + 1))

        sorted_ids = sorted(
            rrf_scores.keys(), key=lambda x: rrf_scores[x], reverse=True
        )
        return [doc_map[doc_id] for doc_id in sorted_ids]

    def search(
        self, query: str, query_vector: List[float], top_k: int = 5
    ) -> List[Dict[str, Any]]:
        # 1. Vector Search
        qdrant_res = self.qdrant.search(
            collection_name=self.collection_name,
            query_vector=query_vector,
            limit=50,
        )
        dense_hits = [hit.payload for hit in qdrant_res if hit.payload is not None]

        # 2. Sparse Search
        sparse_hits: List[Dict[str, Any]] = []
        if self.bm25_model:
            tokens = query.lower().split()
            scores = self.bm25_model.get_scores(tokens)
            top_indices = sorted(
                range(len(scores)), key=lambda i: scores[i], reverse=True
            )[:50]
            sparse_hits = [
                self.bm25_corpus[i] for i in top_indices if scores[i] > 0
            ]

        # 3. RRF Fusion
        fused = self._reciprocal_rank_fusion(dense_hits, sparse_hits)
        if not fused:
            return []

        # 4. Cross-Encoder Re-Ranking
        passages = [
            {"id": c["chunk_id"], "text": c["text"], "meta": c}
            for c in fused[:30]
        ]
        request = RerankRequest(query=query, passages=passages)
        reranked = self.reranker.rerank(request)

        # 5. Confidence Threshold Filtering
        final_results: List[Dict[str, Any]] = []
        for item in reranked[:top_k]:
            if item["score"] >= self.confidence_threshold:
                meta = dict(item["meta"])
                meta["relevance_score"] = float(item["score"])
                final_results.append(meta)

        return final_results

```

### 6.2 Grounded Generation Service (`src/generation/engine.py`)

```python
from collections.abc import AsyncGenerator
from typing import Any, Dict, List
from openai import AsyncOpenAI

SYSTEM_PROMPT = """You are a precise corporate assistant for Helvetia Consulting.
Your task is to answer the user's question STRICTLY using the context blocks provided below.

STRICT RULES:
1. Base your answer ONLY on clear facts directly mentioned in the Context. Do NOT use outside knowledge or assumptions.
2. If the answer cannot be fully derived from the provided Context, state clearly: "I cannot answer this question based on the available documentation."
3. For EVERY factual claim in your response, append an inline citation referencing the source file and page using this exact format: [Doc: <file_name> | Page: <page_number>].
"""

class GroundedGenerator:
    def __init__(self, api_key: str) -> None:
        self.client = AsyncOpenAI(api_key=api_key)

    def _format_context(self, contexts: List[Dict[str, Any]]) -> str:
        blocks = []
        for ctx in contexts:
            block = (
                f"Source File: {ctx['file_name']}\n"
                f"Page Number: {ctx['page_number']}\n"
                f"Content: {ctx['text']}\n"
                "---"
            )
            blocks.append(block)
        return "\n".join(blocks)

    async def generate_stream(
        self, query: str, contexts: List[Dict[str, Any]]
    ) -> AsyncGenerator[str, None]:
        if not contexts:
            yield "I cannot answer this question based on the available documentation."
            return

        context_str = self._format_context(contexts)
        prompt = f"CONTEXT INFORMATION:\n{context_str}\n\nUSER QUESTION: {query}"

        stream = await self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[
                {"role": "system", "content": SYSTEM_PROMPT},
                {"role": "user", "content": prompt},
            ],
            temperature=0.0,
            stream=True,
        )

        async for chunk in stream:
            delta = chunk.choices[0].delta.content
            if delta:
                yield delta

```

## 8. Non-Negotiable Rejection Criteria

Submissions that trigger any of the following anti-patterns will be automatically rejected:

* ❌ **Missing Source Citations**: Generating factual answers without inline citation tags.
* ❌ **Fabricated Citations**: Generating citation tags pointing to non-existent document names or incorrect page numbers.
* ❌ **Bypassed Confidence Filtering**: Calling the generative LLM when retrieval relevance scores fall below $S_{\text{min}} = 0.35$.
* ❌ **Single-Path Search**: Implementing pure vector lookups without sparse BM25 lexical search.
* ❌ **Missing Re-Ranker Stage**: Passing initial vector results directly into prompt context without cross-encoder re-ranking.
* ❌ **Mutable DTO Models**: Pydantic models defined without `model_config = ConfigDict(frozen=True)`.
* ❌ **Insufficient Test Coverage**: Codebase line coverage falling below $80\%$.
* ❌ **Unresolved Type Errors**: Any static type errors detected under `mypy --strict`.
